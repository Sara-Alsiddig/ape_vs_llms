msconvert (RAW→mzML) → comet (pepXML) → peptideprophet (Target-Decoy, pepXML) → rt (pepXML → Amino acid property).

Comet only needs one input slot, the mass spectrum, so no FASTA input is required. PeptideProphet covers both Peptide identification and Target-Decoy. rt accepts pepXML input.
